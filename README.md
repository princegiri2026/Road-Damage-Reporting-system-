# RoadWatch — Road Damage Reporting System

RoadWatch is a responsive, front-end academic prototype for a CSE 326 project. It demonstrates how community members could report potholes and other road damage, browse a shared issue list, and follow report status.

## Features

- Responsive landing page and issue dashboard
- Report form with location, issue type, severity, and description fields
- Search and status filters for community reports
- Support button to show community interest
- New reports and support counts saved in browser `localStorage`
- Illustrative map artwork and report markers
- Demo disclosure explaining that reports are not sent to a road authority

## Run locally

Open `index.html` in a modern browser. No package installation or build step is required.

## GitHub Pages

Upload the contents of this folder to a GitHub repository. In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub Pages will show the public website URL on that settings page when deployment is ready.

## Scope and limitations

This is a front-end demonstration. The initial reports are sample data; new reports are stored only in the current browser. There is no sign-in, shared database, photo upload service, map API, or municipal connection. The map is an illustration, not a live map.
